# 小苋演示的设计规则

目标：让观众一眼看懂重点，让讲述者自然展开。整体像一本简洁的杂志：大标题、清楚的层级、有节奏的留白，少量明亮颜色帮助记忆。

## 颜色与字形

| 角色 | 颜色 | 用法 |
|---|---|---|
| 纸色 | `#f6f3ec` | 默认背景，适合解释、图像和长一点的内容 |
| 墨黑 | `#191b1a` | 正文、标题，或少量深色强调页 |
| 蓝色 | `#2d43f5` | 关键观点、章节转折、封面与结束页 |
| 荧光黄 | `#e2f34b` | 强调、编号、提示与少量整页换气 |

模板另提供 `coral` 主题作为暖色变化。颜色服务于内容层级，不为每一页换主题。保留稳定的页边距、标题位置与编号习惯。使用模板系统字体栈，避免依赖远程字体；不同设备字体可能略有变化，交付时检查实际环境。

标题与正文通过字号、粗细和间距建立层级，少用装饰、阴影和大面积渐变。整套演示保持同一字体体系。

## 内容与页面节奏

- **标题说重点。** “三件值得先做的事”比“建议”具体；“先完成一次真实交付”比“产品方法论”更适合观点页。标题尽量在 36 个中文字以内，正文尽量在 80 个中文字以内，这些是排版建议，不是必须凑齐或机械截断的限额。
- **每页一个观点。** 要说多个层次，就拆页或改成结构化条目。正文复杂时把解释移进讲者备注，不靠缩小字号解决。
- **布局由关系决定。** 对比用双栏，并列用卡片，有先后用步骤，有日期用时间线；不要把所有内容都放进卡片。
- **连续解释之后留一页换气。** 用一个问题、一句结论或一张图停顿。封面、章节转折和结束页可以更大胆，但整套演示要有主次。
- **图像要有任务。** 用来提供证据、解释过程或建立情境。人物与现场图保留主体，图像说明放在合适位置；没有合适素材就使用纯文字布局。
- **观众需要阅读，讲者需要展开。** 页面负责重点，`notes` 负责故事、证据、过渡和提示。不要用备注藏起观众理解结论所必需的信息。

## 八种版式怎么选

| `layout` | 适合内容 | 建议 |
|---|---|---|
| `cover` | 标题、受众承诺、场合 | 标题简短，副标题解释价值 |
| `statement` | 核心观点、问题、章节转折 | 一句话有力量，不再堆四个条目 |
| `split` | 两个方案、前后变化、文字与图片 | 两侧有可比较的维度；配图时提供 `imageAlt` |
| `cards` | 并列要点、原则、案例 | 通常 2–4 项，标题长度相近 |
| `steps` | 操作流程、行动顺序 | 通常 3–5 步，每步有动词 |
| `timeline` | 历程、阶段、计划 | 通常 3–5 项，在条目标题写日期或阶段 |
| `quote` | 引用、值得记住的一句话 | 引用真实可核实，在正文或备注注明来源；非引用勿伪署名 |
| `end` | 回顾、下一步、联系信息 | 说清观众接下来能做什么 |

## 成品检查

先按真实播放尺寸看页面，再检查最容易出问题的地方：长标题、多条目、长网址、含英文的长单词、竖幅图片。画面没有溢出，标题不会被裁掉，文字与背景对比清楚。减少动态效果偏好应得到尊重。逐页确认内容顺序，再检查目录与讲者备注是否对应当前页面。

审美规则是起点。用户提供品牌、特定版式或明确的设计要求时，以其需求为准，同时保留可读性与稳定交互。
