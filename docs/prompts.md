# 复制一句话，开始制作

先安装 Skill，或者把 `skills/xiaoxian-slides/SKILL.md` 的实际文件路径提供给能读取本地文件、执行命令的 AI 工具。然后附上你的文章、大纲或素材，用下面的提示词开始。方括号里的内容替换为自己的信息。

## 从文章制作分享

```text
使用小苋演示 Skill。请把附件文章做成一份面向[受众]的[20]分钟分享，目标是让大家[理解/学会/采取某个行动]。
沿用默认视觉风格，保留快捷键、目录、全屏与讲者备注。先根据内容组织页面，再实际构建并检查 HTML。
把 HTML 和可修改的 JSON 放到[输出文件夹]，最后告诉我怎么打开。
```

## 从零散材料整理

```text
使用小苋演示 Skill，把下面的材料整理成一份[项目介绍/课程/复盘]。
受众是[受众]，预计讲[10]分钟，最想让大家记住的是[一句话]。
材料里没有的事实请标出缺口。重点内容放在页面，展开和过渡放在讲者备注。
请生成并检查能直接打开的 HTML，同时保留 JSON。
```

## 做一份路演

```text
使用小苋演示 Skill，根据附件制作一份[5]分钟项目路演。
帮助观众理解问题、方案、已有证据和下一步，保留材料里的真实数据与来源；没有证据的部分不要写成事实。
页面要简洁，重点突出。请生成可离线播放的 HTML 和 JSON，并检查每页排版。
```

## 修改已有演示

```text
使用小苋演示 Skill，修改[slides.json 的实际路径]：
第 3 页正文太长，请拆成两页；第 5 页换成两列对比；结尾明确一个行动。
重新生成 HTML 并检查受影响的页面，保留快捷键、目录与讲者备注。
```

## 加上自己的图片

```text
使用小苋演示 Skill。请把[图片文件夹]中的图片用于[演示 JSON 路径]，只选择能支持当前观点的图片。
写好简短图片说明，检查主体有没有被裁切，重新构建能离线播放的 HTML。
```

## 需要交 PPTX 或 PDF

```text
使用小苋演示 Skill。请将[HTML 实际路径]导出为 PDF 和图片版 PPTX，输出到[文件夹]。
检查需要的导出环境并实际运行，验证文件可以打开。PPTX 的文字无需单独编辑，演示交互保留在 HTML 中。
```

## 不会使用终端

```text
我下载了小苋演示，文件夹在[实际路径]，我不会使用终端。
请读取里面的 README 和 skills/xiaoxian-slides/SKILL.md，检查本机环境，帮我从附件材料生成一份演示。
请实际完成构建，把结果放在[文件夹]，告诉我双击哪个文件就能播放。
```
